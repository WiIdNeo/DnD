## Compare Against Monster XP

Don't just sum the monsters' base XP — apply an **encounter multiplier** based on the number of monsters, since multiple monsters increase danger due to action economy.

| Number of Monsters | Multiplier |
|---|---|
| 1 | ×1 |
| 2 | ×1.5 |
| 3–6 | ×2 |
| 7–10 | ×2.5 |
| 11–14 | ×3 |
| 15+ | ×4 |

**Party size adjustments:**
- Fewer than 3 party members → bump multiplier one step **up**
- 6 or more party members → bump multiplier one step **down**
