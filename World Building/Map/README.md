> # General:
> 
> Those maps are based on real tectonic behavior and making all the world realistic. So even if the map will feature known places like `Waterdeep` or `Neverwinter` and I try to keep the Swordcoast like it is now it will change heavily. Especially the Sword-Mountains will shift, and the distances will change. The cities themself will stay the same.

These Maps are in Development. There are Different progressions and attempts and therefore Changes. 

For better understanding and if you like some older maps more feel free to use those, but if you dev them further would be great if you share them here again by a pull request.
